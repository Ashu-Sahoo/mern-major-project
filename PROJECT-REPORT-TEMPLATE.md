# Project Report

## Title
Containerization, Cloud Deployment and CI/CD Automation of a MERN Stack Blog Application

## 1. Introduction
Describe the MERN stack and the purpose of containerization, cloud deployment and CI/CD automation.

## 2. Objectives
- Develop a working MERN blog application using MongoDB, Express.js, React.js and Node.js.
- Use TanStack Query for frontend-backend integration.
- Containerize frontend and backend using Docker.
- Manage frontend, backend and MongoDB with Docker Compose.
- Publish Docker images to Docker Hub.
- Deploy frontend and backend to Google Cloud Run using MongoDB Atlas.
- Automate dependency installation, linting, testing, image publishing and deployment with GitHub Actions.
